# ADR 0001: תקציב בקשות למסך שדולק כל היום

תאריך: 4.10.2026 · סטטוס: התקבל

## הקשר

המסך בבית פתוח 24 שעות ביממה. החשבון ב-Vercel (תוכנית Hobby) כבר הגיע ל-75% ממכסת ה-CPU החודשית
בגלל פרויקט אחר שמושך נתונים בקצב קבוע. צריך לוודא שהפרויקט הזה לא מוסיף לצריכה.

## ממצאים

**בפרויקט אין קוד שרת ב-Vercel.** זו אפליקציית Vite סטטית: אין תיקיית `api/`, אין Server Components
ואין Middleware. Vercel מגיש רק קבצים סטטיים מה-CDN, ולכן הפרויקט צורך 0 Function Invocations ו-0 CPU,
לא משנה כמה זמן המסך דולק. כל הנתונים נמשכים מהדפדפן ישירות לשירותים חיצוניים: Supabase, Open-Meteo, Hebcal.

בדיקה בפרודקשן (`curl -sI` פעמיים ברצף, 4.10.2026): `/`, `/dashboard` וקובץ ה-JS מחזירים
`x-vercel-cache: HIT`, בלי `set-cookie`.

כל הטיימרים והמשיכות שנמצאו בקוד:

| מה | לאן | לפני | אחרי |
|---|---|---|---|
| שעון (`useNow`) | אין רשת, טיימר מקומי | פעם בדקה | ללא שינוי |
| החלפת תמונות (`PhotoFrame`) | אין רשת אחרי הטעינה הראשונה | לפי ההגדרה | ללא שינוי |
| מזג אוויר (`useWeather`) | Open-Meteo | כל 15 דקות, גם ברקע, וגם בכל רענון עמוד | כל 15 דקות, רק כשהמסך גלוי, עם מטמון בדפדפן |
| חגים (`useHolidays`) | Hebcal | בכל טעינת עמוד | פעם ביממה לכל שבוע מוצג |
| רענון מלא של הנתונים (`SupabaseStore`) | Supabase, 9 טבלאות | כל 5 דקות, גם ברקע | כל 15 דקות, רק כשהמסך גלוי |
| חזרה ללשונית | Supabase, 9 טבלאות | בכל חזרה | לכל היותר פעם בדקה |
| עדכונים שוטפים (Realtime) | Supabase, חיבור אחד פתוח | קבוע | ללא שינוי |
| המתנה לאישור מסך (`ViewerGate`) | Supabase | 2 בקשות כל 3 שניות, בלי הגבלה | בקשה אחת; 3 שניות בשתי הדקות הראשונות, אחר כך 15 שניות, ואחרי רבע שעה פעם בדקה; מושהה ברקע |

## החלטות

1. **לא להוסיף שכבת שרת.** העברת הקריאות ל-Open-Meteo ול-Hebcal דרך Function ב-Vercel הייתה יוצרת
   צריכה שלא קיימת היום. המטמון נשאר בדפדפן (localStorage).
2. **Realtime הוא הערוץ הראשי, ומשיכה תקופתית היא רשת ביטחון בלבד.** לכן אפשר להאט אותה ל-15 דקות.
3. **שום משיכה כשהלשונית ברקע.**
4. **"שמיים חיים" מחושבים בדפדפן** (`src/lib/sky.ts`) מתוך שעות הזריחה והשקיעה שכבר הגיעו עם מזג האוויר.
5. **לכל קריאה חיצונית יש `AbortSignal.timeout(10_000)`.**
6. **`ignoreCommand` ב-`vercel.json`** מדלג על build כשה-commit משנה רק קובצי `*.md` או את `docs/`.
7. **קובצי `/assets/*` (עם hash בשם) מקבלים `Cache-Control: immutable` לשנה**, כדי שהדפדפן לא יאמת אותם מחדש.

## בקשות משוערות ליום, למסך אחד שדולק 24 שעות

| יעד | לפני | אחרי |
|---|---|---|
| Vercel Functions | 0 | 0 |
| Vercel CDN (קבצים סטטיים) | רק בטעינת העמוד | רק בטעינת העמוד |
| Supabase REST (מסך מחובר) | כ-2,600 (288 רענונים × 9 טבלאות) | כ-860 (96 × 9) |
| Supabase REST (מסך שממתין על קוד QR) | כ-57,600 | כ-1,500 |
| Open-Meteo | 96 | 96 |
| Hebcal | אחת לכל טעינת עמוד | אחת ביממה |

המספרים הם חישוב מתוך הקוד, לא מדידה בפועל.

## השלכות

- אם יתווסף בעתיד קוד שרת (למשל חיבור ל-Google Photos), צריך לחזור למסמך הזה ולהוסיף לו מטמון בצד השרת.
- שינוי שנעשה במכשיר אחר בזמן שחיבור ה-Realtime נפל יופיע במסך תוך 15 דקות לכל היותר, במקום 5.
